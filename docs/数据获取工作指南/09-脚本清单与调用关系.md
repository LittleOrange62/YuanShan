## 0. 一句话流程

```
通达信客户端登录 ──▶ P0 盘后下载（拟人点击）──▶ vipdoc/ 落文件
                                                    │
                          ┌─────────────────────────┴──────────────────────┐
                          ▼                                                ▼
              C 类：解析 vipdoc 文件入库                       T 类：走 TQ 本地 RPC 入库
        c1 日线 / c3 板块 / c16 分钟 / c15 收盘快照         c18 板块成分 / c19 除权除息 / c20 个股档案

        N 类：网络 c4 份额 c5 两融 c6 龙虎榜 c8 分红 c9 股本 c11 大盘资金流 c21 新浪个股榜 c22 同花顺板块榜 c24 东财板块页对表 c25 财务多期 ─┤
                                                            ▼
                                              E 类编排：e1 一键追平 → compute 派生层 → e2 质量审计
```

日常只需记一条：**`python -m ingest.jobs.e1_fill_all`**（或整链 `daily_close_sync`）。
