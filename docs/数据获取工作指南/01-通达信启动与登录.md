# 01 · 通达信启动与登录

目标状态：**TdxW.exe 在当前桌面会话里运行、已登录、无弹窗遮挡、指数行情已自动同步完成**。

> 每一步先看「怎么判断已完成」。**已达成就跳过这一步**，不要重复操作 ——
> 重复登录会弹"已在别处登录"，重复点菜单会误触。
>
> 本文脚本路径全部相对项目根 `D:\finance\YuanShan`；旧的操作脚本已归档在本项目的
> `ingest\legacy\` 下，可以直接跑。开跑前先 `cd /d D:\finance\YuanShan`。

---

## 步 0 · 确认自己在正确的会话里

```powershell
# 当前进程的会话 ID
(Get-Process -Id $PID).SessionId
# 已登录用户的会话 ID
query session
```

**成功标志**：两者一致，且 `query session` 里你的用户状态是 `Active`。

**失败表现**：`SessionId = 0`。此时后面所有窗口枚举都会返回空列表，看起来像"通达信没开"，其实是看不到。必须改用登录用户会话内的进程执行。

---

## 步 1 · 检查是否已经登录（先查再动）

```powershell
# 列出 TdxW 的所有顶层窗口
powershell -File "ingest\legacy\02_通达信操作\win_enum.ps1" -TargetPid (Get-Process TdxW -ErrorAction SilentlyContinue).Id
```

或者直接看进程与窗口标题：

```powershell
Get-Process TdxW -ErrorAction SilentlyContinue | Select-Object Id, MainWindowTitle
```

**已登录的标志**：主窗口标题包含 `通达信金融终端`（当前版本是 `V7.73`）。

**未登录的标志**：进程在、但标题是 `通达信` + 版本号的登录窗（无"金融终端"字样），或者根本没有 TdxW 进程。

- 已登录 → **跳到步 5**
- 未登录 → 继续步 2

---

## 步 2 · 关闭并重启通达信

```powershell
taskkill /F /IM tdxw.exe
Start-Sleep -Seconds 2
Start-Process -FilePath "D:\new_tdx64\TdxW.exe" -WorkingDirectory "D:\new_tdx64"
```

**成功标志**：30 秒内 `Get-Process TdxW` 有结果。

**失败表现**：`taskkill` 报"找不到进程"是正常的（本来就没开），不用管。若 `Start-Process` 后进程起来又马上退出，通常是上一次没干净退出留了锁，等 5 秒再试一次。

## 步 3 · 填账号密码并登录

### 推荐做法：一键脚本

```powershell
powershell -ExecutionPolicy Bypass -File "ingest\legacy\02_通达信操作\open_tdx.ps1"
```

这个脚本做 5 件事：检查是否已登录 → 启动 TdxW → 填账号密码点登录 → 3 轮关弹窗 → 最小化到托盘。
账号密码在它的 `param` 默认值里（`$User` / `$Pass`）。

它定位输入框的方式是：枚举登录窗子控件，收集 `class = SafeEdit` 的，**按 Y 坐标排序**，上面那个是账号、下面是密码。**窗口尺寸或系统 DPI 变化会让这个假设失效**，见 [03-故障排查.md](03-故障排查.md#登录框定位错位)。

### 关键细节：输入框可能已经有内容

通达信会记住上次的账号密码。**直接输入会拼接成错误的字符串**，必须先清空：

```
点击输入框 → Ctrl+A → Delete → 再输入
```

`type_creds2.ps1` 里就是这个做法（`type_creds.ps1` 没清空，别用那个）。

### 验证账号真的填进去了

```powershell
# 读输入框当前内容（UIA 路线，更可靠）
powershell -File "ingest\legacy\02_通达信操作\edit_read_uia.ps1"
# 或 Win32 路线
powershell -File "ingest\legacy\02_通达信操作\edit_read.ps1"
```

**成功标志**：账号框内容 == `18969969696`，密码框为掩码但长度 == 11。

### 只需要点登录（账号密码已填好）

```powershell
python "ingest\legacy\02_通达信操作\login_tdx.py"
```

它用 pywinauto 找 `Button` 且文本为 `登录` 的控件，发 `BM_CLICK`，然后**轮询到 `verify_timeout = 60` 秒**（`app/tdx_client/steps/s2_login.py:247`；本文原先写 90 秒，是改小之后的旧数）等主窗口标题出现终端名。

**成功标志**：脚本退出码 0，且主窗口标题含"金融终端"。

**失败表现**：
- 提示"用户名或密码错误" → 口令写成 `Chengzi888` 了（正确是 `Chengzi.888`，带点）
- 提示"该账号已在别处登录" → 上一个实例没退干净，回步 2 重来
- 90 秒超时但窗口其实已经出来了 → 标题里的版本号变了（通达信升级过），需要放宽匹配

## 步 4 · 关闭登录后的弹窗

登录后会连续弹好几个窗口（资讯、公告、活动），数量和标题**不固定**。

```powershell
# 关标题含"通达信"的弹窗
python "ingest\legacy\02_通达信操作\close_tdx_popup.py" "通达信"
# 明确点名"通达信信息"窗口
python "ingest\legacy\02_通达信操作\close_tdx_popup.py" "通达信信息"
```

脚本对每个匹配窗口依次尝试 4 种方法，每步用 `IsWindow` / `IsWindowVisible` 验证：

1. `SendMessage WM_CLOSE`
2. `WM_SYSCOMMAND SC_CLOSE`
3. `SetForegroundWindow` + 发 ESC / ENTER
4. PowerShell `AppActivate` + `Alt+F4`

**成功标志**：再次枚举窗口时，除主窗口外没有可见的通达信弹窗。

```powershell
python "ingest\legacy\02_通达信操作\list_all_windows.py"
```

**要点**：弹窗**随时**可能再出来（包括后面下载过程中）。所以这一步不是"关一次就完"，
而应该在整个流程期间**反复关**。跑两三轮：

```powershell
1..3 | ForEach-Object { python "ingest\legacy\02_通达信操作\close_tdx_popup.py" "通达信"; Start-Sleep -Seconds 2 }
```

**不要盲关所有窗口** —— 遇到没见过的标题，先记下来再决定，别把"盘后数据下载中"这种正在干活的窗口关掉了。

## 步 5 · 等指数行情自动同步完成

登录后通达信会**自动**同步指数行情（个股盘后日线不会自动下，要手动，见 [02](02-盘后数据下载与入库.md)）。

同步由 `TPyth*` 进程执行（TQ 插件，DLL 在 `D:\new_tdx64\PYPlugins\TPythClient.dll`）。

```powershell
# 看同步进程还在不在
Get-Process | Where-Object { $_.ProcessName -like 'TPyth*' } | Select-Object Id, ProcessName, StartTime
```

**成功标志（两个条件都要满足）**：

1. `TPyth*` 进程已退出
2. 指数 `.day` 文件的最后一条记录日期 == 目标交易日

第 2 条这样验：

```powershell
cd D:\finance\YuanShan
$env:PYTHONIOENCODING='utf-8'
$code = @'
from app import config
from app.ingest.tdx_binary import parse_day
for name in ('sh999999.day', 'sh000001.day'):
    p = config.VIPDOC_DIR / 'sh' / 'lday' / name
    if p.exists():
        bars = list(parse_day(p))
        print(name, '最后一条:', bars[-1].trade_date, 'close', bars[-1].close)
'@
$code | python -
```

**失败表现**：
- `TPyth*` 一直在（超过 10 分钟）→ 可能卡在网络重连，看 `tq_fetch_log.txt`（归档件在本项目 `legacy\日志\`；`update_2026_data.py` 跑起来写在 `DATA_DIR`，即 `D:\finance\data`）
- 进程早就没了但日期还是旧的 → 同步失败且没报错，回步 2 重启重来
- 出现"通达信信息"窗口 → 按步 4 关掉，它会阻塞同步
