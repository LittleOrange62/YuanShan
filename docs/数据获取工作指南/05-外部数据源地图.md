## TQ 下载文件的落盘位置（实测 + 官方口径）
- 常规行情/财务：**`D:\new_tdx64\vipdoc`**（按市场 sh/sz/bj 分目录的 .day/.lc1/.lc5）
- TQ `download_file` 类指令（十大股东、ETF 申赎清单等）：**`D:\new_tdx64\PYPlugins\data`**
- 收盘快照手工链路：`PYPlugins\user\Get_DayEnd.py` → **`D:\new_tdx64\daily_close_data.db`**（每日一表 `day_end_YYYYMMDD`，整表覆盖，c15 读它入库）

## 选型纪律（从 9 月这三天的实测提炼）
1. 同一字段多源并存时，**质量规则以 vipdoc/TQ 为裁判**（akshare 东财口径 OHLC 常有 1e-2 级差，c10 的"投票定日"就是为此设计的）。
2. 免鉴权源（东财/腾讯/akshare）都要假定"随时可能变脸"：接入必须带 `config.datasource` 探活行 + `operations.datasource_probe` 历史，坏了页面上看得见，不要静默失败。
3. 有配额的（tushare）先实测档位再登记（做法：`.env` 注释 + registry 页 no_permission 灰显），别照抄文档。
4. 本表只覆盖**本工作区**。另外四个项目（Vibe-Trading / TradingAgents-astock / quantdash / YuanShan）各有一整套取数层，对照与"哪些思路值得抄、哪些代码不能搬"见 [06-跨项目数据源对照](06-跨项目数据源对照.md)。
