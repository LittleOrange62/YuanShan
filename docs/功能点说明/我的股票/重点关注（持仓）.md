### 2.1 面板说明（`Caliber` 气泡「口径」原句，`:224-233`）

点 `?` 口径按钮弹出（`frontend/src/components/ui/Caliber.tsx`：`onClick` 开合、`Esc` 关、点空白关，
正文过 `plain()` 剥粗体标记），原句五行：

```
持仓不是单独的一本账，而是**交易日志的一个视图**：
把日志里所有成交明细折算下来，还剩多少就是持仓多少。

· 成本按剩余股数的加权均价算（与券商的移动加权口径一致）。
· 同一只票在多笔交易里都有剩余时合并成一行。
· 建仓 / 加仓 / 平仓都去交易日志改那笔的成交明细，这里会跟着变。

⚠️ 行情取不到时那一行显示「行情不可用」，不会显示成 0 ——
显示 0 会让市值变 0、盈亏变 −100%，看着像持仓归零，那是假的。有这种行时，上面的合计也会标成「不完整」。
```

② 合并一行时「计划止损」取的是该代码所有未平仓记录里的**最低**一个（`positions.py:172` `min(...)`），

这一条比"界面显示错"更硬：一旦把持仓喂给模型，用户的成本与浮盈就成了模型的语境，
而本项目合规立足点是**不给个性化投资建议**（同一处判据的原话在 `duanxian/attribution.py:179-183`：
"⛔ 不要把它接进任何 AI prompt … 个人数据只走只读 API 给前端渲染，AI 永远看不到"；
模块级声明在 `duanxian/positions.py:16`、`duanxian/journal.py:9`、`Portfolio.tsx:37`）。

### 4.1 实现落点是"登记侧"，不是"按钮侧"

`frontend/src/lib/workspace/pageAskAiStore.ts:16-18`（注释原句）：

> 也刻意不做"没登记时拿别的东西兜底"—— 持仓页（`/my-stocks`）永远不登记，
> 那是"持仓数据不接入任何 AI prompt"那条红线的界面侧落点。

⇒ **不登记 = 那一格就没有输入框**，栏也不会去猜"现在大概是哪一屏"。

## 6. 每个读数的口径：用的是哪一把尺子，除权日会怎么显示

### 6.1 逐读数定性

| 读数 | 用未复权还是复权 | 出处 | 除权除息日会怎么显示 |
|---|---|---|---|
| **现价** | **未复权的实时原始价**（交易所此刻报价，钱本位） | `positions.py:154` → `_quotes()` `:31-44` → `vr/astock.py:93-95` `tencent_quote()` → `qt.gtimg.cn` 字段 3（`_parse_gtimg` `:51-92`，`"price": num(3)` `:71`）。**这一屏根本不读 `market_data.stock_daily`** | 价格本身**会**因为除权而机械下调 —— 交易所就是这样挂的，这是"真钱" |
| **成本** | **未复权**：用户手填成交价（`fills.price`）的移动加权均价，不含费用 | `journal.py:370`（`pos_cost += f["price"] * f["shares"]`）、`:399-404`；跨笔加权 `positions.py:74/83` | **不变**：成本是历史成交额的算术结果，系统不会因为某天除权去还原它（也没有 `adjustment_factor` 可用） |
| **成本额 / 市值 / 浮盈（元）** | 未复权 × 股数，**金额层面是真的**（市值就是这个价能卖多少、成本就是当时花了多少） | `positions.py:158/168-170` | 分红到账后：价掉、成本不动 ⇒ **浮盈（元）与浮盈% 一起机械变差**，屏幕上看着像"今天亏了"，实际权益守恒（价 + 已到账现金）。界面**没有任何复权处理，也没有这句提示** |
| **浮盈%** | `现价 ÷ 成本 − 1`（未复权 ÷ 未复权 ⇒ 同尺，但**与全站"涨幅"那族不同尺**） | `positions.py:171` | 同上 |
| **计划止损** | 用户手填价，未复权，跨笔取最低 | `positions.py:78-79/172` | 除权后若不去日志改那个数，会出现"止损价高于现价"这种已失效的边界（页面只显式说明"那是未设不是零"，`Portfolio.tsx:383-384`） |

### 6.2 「同名不同尺」必须点名的一处

本仓库在涨幅口径上刚统一过一把尺子：**`close × adjustment_factor` 是后复权价、跨除权日连续**
（定义在 `app/db/repo/quote.py:444`，实测校验 002594.SZ 2025-07-29 十送二十）；
`stock_daily.pct_change` 是**未复权**的原始比值；判据只住 `duanxian/day_returns.py`
（`:6-13` 两条裁定，`RULE_NOTE` `:16-27` 原句："除息日那一格会和行情软件的原始涨跌幅对不上 ——
那个差就是派息，复权口径才是对的（实测 000155 在 2026-09-22：未复权 −2.77%／复权 −0.60%）"）；
总表在 [页面展示工作指南/01-数据口径展示规范.md](../../页面展示工作指南/01-数据口径展示规范.md):220。

于是这一屏与那一族**是三把不同的尺，都叫"涨/亏"**：

| 屏幕上那个百分数 | 尺子 | 基准 |
|---|---|---|
| 本屏「浮盈%」 | **未复权实时价 ÷ 未复权手填成本 − 1** | 你自己的成交时刻与价格，跨不了除权日 |
| 倍量形态那屏「当日涨幅 / 15 日涨幅」 | **后复权**（`close × adjustment_factor`），按市场场数取基期 | 库里那一档收盘价 |
| `/api/watchlist/*` 交的 `avg_pct`/`pct_change` | **`stock_daily.pct_change` 未复权**（`duanxian/watchlist.py:87`、`:130`） | 当日日线原始比值（这一屏的下拉不显示它，只有 `stock_count`） |

**这不是谁写错了，是三件事**：本屏要回答"我这笔现在值多少钱"，所以必须用真钱（未复权）；
选股那族要回答"它涨了多少"，所以必须复权。屏幕上没有任何一处把这层差别写出来 ——
「标的」列链去东财，东财那页显示的涨跌幅是**未复权原始比值**，与本屏「浮盈%」不同基准（一个对昨收、一个对你的成本），
而列头悬停只写了「与「浮盈」是两个口径：仓位不同结论可能相反」（`Portfolio.tsx:382`），**没写与复权口径的关系**。

仓库里已经有一条同类声明可指路（但**不在这一屏**）：`duanxian/excursion.py:277` 的 note 明说
「本模块以**未复权日线**对照**手填成交成本**，遇除权除息、拆股或送转时两者可能不可比，应人工核对，不据此判断真实得失」——
那是 MFE/MAE 那块（`/journal`）。**同一件事在持仓这一屏没有对应的那句话**，本文件把它写下来。

## 10. 不许破的纪律（红线优先）

1. **⛔ 持仓页禁止任何 AI 入口**（用户定的红线，本屏最硬的一条）。落点是"这一屏永不登记进
   「问 AI · 本页上下文」的可查页清单"（`pageAskAiStore.ts:16-18`），屏幕证据 `AiAnalysisPanel.tsx:115-120`
   （`:118` 原句「持仓（重点关注）永远不登记 —— 成本与盈亏不接入任何 AI」），回归闸
   `tests/test_core_logic.py:6520-6534`（`Portfolio.tsx` 源码里不许出现 `AskAiButton`/`AskAiChat`/`usePageAskAi`/
   `pageAskAi`/`aiContext`/`pageMaterials`/`chatStream`/`/chat` 任一串）。后端侧同一条写在
   `duanxian/positions.py:16`、`duanxian/journal.py:9`、`duanxian/attribution.py:179-183`，

   里没有闸 —— 见第 4.3 表。
2. **持仓不是另一张表**：唯一账本是 `journal`，`positions.py` 只做聚合、不许落盘
   （`tests/test_core_logic.py:7296-7302`）。要改数量去 `/journal` 改那笔的成交明细，
