### 3.1 长文本与 markdown 残留（本项目「渲染后纯文本不该出现 `**`」审计在本屏的落点）

- 正文走 **ReactMarkdown 真渲染**，粗体标记被解析消费，不进 `innerText`——审计口径成立。
  实测 2026-10-11：`/notes` 屏幕 `document.body.innerText` 中 `**` 计数 = **0**（当前存储为空数组，见 §6；空屏取证弱，正文有记录时应重数一遍，方法见 §7）。
- **`plain()` 不用于本屏，且刻意不许用**：`frontend/src/lib/agent.ts:62-66` 那个只剥成对粗体的 `plain()` 是给**后端散文字段**（caveats/note 一类）收尾用的；
  用户/AI 正文按审计纪律不包 `plain()`（包了等于把 markdown 源文当纯文本露星号）。本屏没有任何后端散文要剥，`:33` 直接渲染即可。
- 搜索框匹配 `**` 原文不算泄漏：命中的是存储源文，屏幕仍只有渲染后文本。

## 5. 红线：研究记录/复盘笔记/提醒内容绝不进任何 AI 提示词

**结论：本屏有一处全局 AI 入口，但代码上带不出任何研究记录内容；红线是三层独立实现的，不是靠"没按钮"。**

1. **存储层（最硬的一层）**：`vr-notes` 只活在浏览器 localStorage，服务端从不持有、也无从读它。
   2026-10-11 grep 实测：`vr-notes` 在 `frontend/src` 仅 `notes.ts:12` 一处，在 `duanxian/`、`review_agent/`、`vr/`、`server.py` **0 处引用**；
   `GET /api/research-notes`、`GET /api/notes` 均 404。数据不出浏览器 ⇒ 任何 prompt 组装代码物理上拿不到它。
   `notes.ts:2` 原话：「只存本地 localStorage，不上传、不进仓库。」
2. **页面登记层**：全局「问模型/问 Agent」浮层（`Layout.tsx:86` 触发、`:108` 挂 `WorkspaceChat`，`/` 与 `/settings` 除外每屏都在，本屏也算"有 AI 入口"）
   发送体只有 `{anchor, question, conversation_id, llm, scope:{mode,page,allow_network:false,symbol:''}}`（`WorkspaceChat.tsx:110-111`）——
   question 是用户手打的（上限两千字 `:97`），**没有任何字段来自 `vr-notes`**。浮层标题走 `chatPageFor('/notes')`='研究记录'
   （`modules.ts:66`），即 `聊聊「研究记录」`，但它只是会话分组标识，不是数据通道。浮层自述（实测到屏原句，`WorkspaceChat.tsx:142`）：
   「普通对话仅发送问题与本会话历史，不读取页面、复盘或本地文件。」
   右侧「AI分析」栏的「问 AI · 本页上下文」在本屏显示「这一屏没有登记可带的本页材料，所以这里不放一个点了没反应的输入框。」
   ——因为 `ResearchNotes.tsx` **不调 `usePageAskAi`**；全库登记在册的只有首页盘面、个股研究、自选股三页，
   由 `tests/test_core_logic.py:6536 test_ai_rail_reads_the_page_registry` 钉死（登记侧白名单）。持仓页同款红线钉在 `:6520 test_portfolio_page_feeds_nothing_to_ai`。
3. **提示词槽位白名单**（另一份文档查到的 `prompt_slots.py` 一族，本轮核实）：一键「深入分析」话术的占位符白名单住在
   `duanxian/prompt_slots.py` 的 `SCOPES`（`:67-93`）——只有 `lianban`（盘面数据·连板股那一行，13 个行情字段）与
   `firstboard`（首板分析那一行，11 个字段）两族，**没有任何研究记录/笔记/提醒字段**；用户自建模板只能复用同一张字段表
   （`save_custom` 拒绝未知类型 `:265-266`，`_check_text` 保存时逐占位符拒绝未知键 `:160-178`，判定函数 `unknown_placeholders :154-157`）。
   ⇒ 机制上连"配置页手打一个 `{note}` 占位符"这条路都被存不进去。
4. **同族红线旁证（写清楚谁管谁）**：`duanxian/journal.py:9`、`duanxian/review_notes.py:18`、`duanxian/positions.py:16`、
   `server.py:972`、`vr/app.py:1699`、`frontend/src/pages/Journal.tsx:21-22,1730-1734` 都明文「**不接入任何 AI prompt**」，
   管的是流水/复盘笔记/提醒/持仓（`~/.duanxian-agents/journal/` 与 `ys.review_note`/`ys.reminder`），**不是** `vr-notes`；
   测试侧 `tests/test_core_logic.py:1063 TestPersonalDataNeverReachesPrompt` 锁的是喂 prompt 的十个模块不得 import journal/risk/attribution。
   研究记录不需要这类 import 检查——它根本没有服务端数据面；两层（不出浏览器 + 不登记上下文）已经足够。
5. **方向核对**：唯一的跨层数据流是 **AI 产出 → 研究记录**（§4，用户逐条点保存），与红线方向（记录 → prompt）相反，不违规。
   边界只剩用户自己：把已存正文复制进「问模型」输入框是人的动作，代码管不到——本屏不自动带。

⚠️ 专用回归测试：**没有**（2026-10-11 grep：`tests/` 与 `frontend/test/` 均无 `ResearchNotes`/`vr-notes` 字样）。
红线目前由架构 + §5.2/5.3 引用的既有测试间接守着；给 `vr-notes` 加任何上行通道时，必须先补钉这个面的测试（列入 §8）。

## 8. 不许破的纪律

1. **红线（§5 全部）**：研究记录/复盘笔记/提醒内容绝不进任何 AI prompt。三层落点各钉各的——`vr-notes` 不许出现任何上行代码（现在 0 处）；
   `ResearchNotes` 不许登记 `usePageAskAi`；`prompt_slots.SCOPES` 不许加 note/笔记/提醒一族字段（要加先过用户裁定 + 补测试）。
2. **读取严格、坏一条判整库**：`loadNotes` 的校验（`notes.ts:18`）故意不做单条跳过降级——`addNote/deleteNote` 都是"整数组读回→改→整数组回写"，
   静默跳过坏记录等于下一次写入把它永久抹掉（丢一条就是永久丢失，同 `journal.py` 的 JournalCorrupted 立场）。
3. **写失败不许装成功**：`persist` 抛错原句带「原记录未改动」（`notes.ts:27`）；保存按钮失败进 toast，不显示「已存入研究记录」。
4. **硬删只此一路、先确认**：无软删无版本，「此操作无法撤销」那句（`ResearchNotes.tsx:15`）不许删；导出 JSON 是唯一备份，副标题那句要留着。
5. **正文不包 `plain()`**：markdown 一律 ReactMarkdown 渲染；审计门禁只看渲染后 `innerText` 里 `**`（`plain()` 住的 `lib/agent.ts:62-66` 只给后端散文字段收尾，与本屏无关）。
6. **行情外链纪律在本屏的落点**：本屏**没有**个股名→行情的链接（不用 `StockLink`），`StockLink.tsx:12,26` 的「一律新标签打开」管不到 markdown 正文——
   正文链接走 react-markdown 默认 `<a>`（同标签页）。给本屏加 `components` 覆写（强制 `target="_blank" rel="noopener noreferrer"`）之前，
   不许把"AI 正文里的行情链接"当成本屏功能点来宣传；也别在列表里用 `<b>{title}</b>` 处渲染富文本（标题按纯文本处理，含 `**` 或 `问 AI · ` 前缀都在所不惜——那是数据原样）。
7. **屏幕语言 = 存储语言**：副标题说「本浏览器保存」，就不许哪天悄悄加个"同步到库"而不改这句；跨浏览器/跨机器不同步、跨标签页不实时（无 storage 事件监听），都是既有边界不是 bug。
8. 本屏没有的东西别硬造：无 caveats/definitions/coverage/provenance（没有接口）、无排序（不是表格）、无分页（列表全量渲染）；记录多了渲染变慢属性能问题，届时另立方案，别顺手加"后端来管"。

## 9. 与「交易日志」（`/journal`，三 tab）的分工——别互相抄

| | 研究记录 `/notes` | 交易日志 `/journal` |
|---|---|---|
| 记什么 | **AI 产出的沉淀**：问 AI 回答、近7日要点、连板/首板深析（markdown 自由文本） | **自己录入的账**：交易流水（`~/.duanxian-agents/journal/trades.json`，`journal.py:13`）、按行情日 13 格复盘笔记（表 `ys.review_note`，`review_notes.py:28,46`）、到期提醒（`ys.reminder`，`:29`） |
