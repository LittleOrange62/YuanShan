# 02 · TQ 接口与策略脚本

## TQ策略是什么

通达信客户端内置的**量化/策略插件子系统**。它把客户端能力通过
`D:\new_tdx64\PYPlugins\TPythClient.dll` 暴露成 Python 接口，SDK 是
`PYPlugins\user\tqcenter.py`（v1.0.14，2026-07-03），核心对象 `tq`。

DLL 导出的能力（决定 TQ 能干嘛）：

| 接口 | 用途 |
|---|---|
| `GetTdxDataStr` | 通用数据：行情/财务/板块/除权/快照 |
| `GetProDataInStr` | 专业数据 |
| `TdxFuncMain` | 调通达信内部函数（公式/指标） |
| `GetOrderStr` | **下单**（实盘/模拟） |
| `SetMsgToMain` | 把数据回传客户端（选股结果、加板块、画线） |
| `Register_DataTransferFunc` | 注册回调 |

支持品种后缀：`SH/SZ/BJ` A股、`OF` 场外基金、`CSI/CNI` 指数、
`CFF/SHF/DCE/CZC/INE/GFE` 期货、`SZO/SHO` 期权、`HK/US` 港美股。

## 硬约束（务必记住）

1. **必须客户端已启动且已登录**——TQ 是连到运行中客户端的本地 RPC（`127.0.0.1:17709`），不是离线读文件。
2. **单连接**——`tq_bridge` 用固定脚本名 `_ft_tq_bridge.py`，同一时刻只能跑一个 TQ 片段，别并发。
3. **数据新鲜度分档**：行情实时；日线/分钟线要盘后下载过；财务/除权是服务器缓存。

## 两种用法

### A. 挂进 TQ策略菜单的常驻脚本

在 `D:\new_tdx64\PYPlugins\user\` 放一个 `.py`，骨架：

```python
from tqcenter import tq
tq.initialize(__file__)
data = tq.get_market_data(stock_list=['600519.SH'], period='1d', ...)
# ... 处理 ...
tq.close()
```

现成例子在**通达信安装目录**里，不在本项目树内（10-18 现查：`find . -iname "*tdxdata*"` 在本项目零命中）：
`D:\new_tdx64\PYPlugins\user\tdxdata_test.py`（**distinct `get_*` 名 32 个、含 `get_` 的行 37 行** —— 原先这里写的"101 个"是从别处抄来的，对不上这个文件）、
`D:\new_tdx64\PYPlugins\user\Get_DayEnd.py`（每天生成 `daily_close_data.db`，即 c15 的数据源）。
⚠️ 这两个文件是**客户端侧**的，本项目不复制它们、也不从代码里按绝对路径去调它们（那条已被 doctor 的第 9 项 External-refs 闸列为违规）；
要看本项目的现役写法就看 §B 的 `app/tdx_client/tq_bridge.py` 与 `docs/数据加工工作指南/脚本/tq_fetch.py`。

### B. 从项目里临时驱动客户端（推荐，本项目全用这个）

不污染通达信安装目录，用 `app/tdx_client/tq_bridge.py`：
它把一段用 `tq` 的代码临时写成脚本丢进 `PYPlugins\user\`、起子进程跑、
从结果文件读回来、跑完即删。

```python
from app.tdx_client import tq_bridge
r = tq_bridge.run_snippet('''
    m = tq.get_more_info(stock_code='600519.SH')
    emit({"main": m.get("MainBusiness"), "zt": m.get("ZTPrice")})
''', timeout=120)
print(r)   # {'main': '茅台酒', 'zt': '1379.18', 'ok': True}
```

`run_snippet` 约定：片段里可直接用 `tq`、`emit(dict)`、`OUT_DIR`（可写目录）；
异常会被转成 `{'ok': False, 'error': ...}`。取全市场那种要跑几分钟的活传 `stream=True`
（进度实时回显，结果从 `var/tq_bridge_result.json` 读）。

## 常用 tq 函数速查（实测返回结构）

| 函数 | 返回 | 备注 |
|---|---|---|
| `get_market_data(stock_list, period, start_time, end_time, dividend_type)` | DataFrame dict（每列一个字段） | `dividend_type='none'` 取未复权原始价 |
| `get_more_info(stock_code)` | dict，80+ 字段 | 当日档案：MainBusiness/ZTPrice/DTPrice/Zsz(亿)/DynaPE/PB_MRQ/StaffNum… |
| `get_relation(stock_code)` | list[{BlockCode, BlockName, BlockType, GPNume}] | 个股所属板块；BlockType∈行业/概念/地区/风格。注意风格类 BlockCode 可能是 "0" |
| `get_stock_list_in_sector(block_code)` | list[ts_code] | 板块成分，如 `get_stock_list_in_sector('880301.SH')` |
| `get_sector_list(list_type=0)` | list，如 `['880081.SH', ...]` | 板块指数列表 |
| `get_divid_factors(stock_code)` | DataFrame，索引 Date，列 Type/Bonus/ShareBonus/Allotment/AllotPrice | **每10股口径**，入库要 /10（见 05） |
| `get_gb_info(stock_code, date_list, count)` | list[{Date, Ltgb(流通股本), Zgb(总股本)}] | 股本 |
| `get_financial_data(stock_list, ...)` | DataFrame | 财务 |
| `exec_to_tdx(url)` | dict | 点命令：`.933` 盘后下载 / `.934` 数据维护 / `.930` 系统设置 |

## 本目录的 `tq_fetch.py`

把上面这些封成命令行，随手查一只票：

```bat
python 脚本\tq_fetch.py 600519.SH            :: 全都要
python 脚本\tq_fetch.py 600519.SH --what sector
python 脚本\tq_fetch.py 600519.SH --what divid
```

前提同样是通达信已登录。它只取来打印、不写库，适合核对通达信口径。
