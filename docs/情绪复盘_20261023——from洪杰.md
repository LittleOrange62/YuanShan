**主线是「机器人产业链 + AI应用/影视」的低位首板与深水反包，不是高位接力。** 84家涨停中首板占85.7%，54只是昨日下跌股反身涨停，20只盘中跌破-5%后仍封板——赚钱效应集中在"低吸核按钮"，而非"追高度"。

- 最低跌破-3%的涨停股：40/84（47.6%）
- 最低跌破-5%的涨停股：20/84（23.8%）

- 板块集中于机器人/自动化设备、AI应用、电子。**资金偏好低吸核按钮，追高意愿弱。**

**异动规避型趋势（横盘消化后再新高）**
- **四通股份**：近60日 +107.9%，近20日仅 +8.8%（长期横盘），今日涨停创阶段新高——典型规避异动后二次启动。
- **华瓷股份**：近60日 +104.7%，近20日 +41.4%，今日涨停。
- 反例：慈文传媒近20日 +93.4%（连续拉升），属显性异动而非规避型；海洋王60日+148.6%但连续6板，是纯情绪高度票。

## 结论

今日核心赚钱效应 = **机器人产业链低位首板 + 深水反包修复**（不是高位趋势反包，也不是纯低位补涨）。可参与方向是"低位/中位首板 + 日内深水低吸"，回避中位2进3与高位独苗接力。
