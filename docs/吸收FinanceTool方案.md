### 0-0-4. 数据流三步（用户定义，写死在这里）

```
第一步 采集     各维度取数 ──写──▶ PG
第二步 加工计算   脚本读 PG ──算──▶ 结果再写回 PG      ← 这一步也要写库，不是只在内存里算完就丢
第三步 展示     页面读 PG 把结果呈现出来               ← 展示形态参考各项目，但代码与数据都在本项目
```

**PG 权限**：用户明确「你拥有这个 PG 库的增删改查最大权限」，并且「**只有你能写**，读的话可能会有别的人来读，
但写、更新和删除就只有你能做」。所以"没权限"不再是任何一项工作的阻塞理由；反过来，
**唯一写方是本项目**这件事现在是硬约束 —— 谁再往 PG 起第二个写入进程（包括旧项目那条计划任务、
包括本项目里一条不该留的 `--legacy` 分支），就是直接把"谁对谁错"变成不可判定。

三条位置禁令（从现在起生效，适用于所有会话）：

| 允许 | 禁止 |
|---|---|
| 代码写在本项目根下（采集/计算落在 `ingest\`、`compute\`） | 在参考项目目录下新建或修改任何文件 |
| 文档写在 `docs\`（四本指南已在此，别家说明书在 `docs\参考\`） | 文档里出现指向参考项目的绝对路径或"去那边跑/看"的指路 |
| 跑法一律 `python -m <本项目模块>` 或本项目内脚本 | `sys.path.insert`、`subprocess` 指外部仓库、`cd /d` 到外部目录 |

⚠️ **禁止写 ≠ 我们来删**。参考项目什么时候消失由用户决定；本项目不主动删那个目录
—— 它是这批能力的**唯一原始出处**，`diff` 比对、口径追溯都还要用它。我们做的只有：
不再依赖它、把它该带走的东西（说明书、`var/` 不可再生数据、`.env` 里唯一的口令）先复制到本项目。

   （第二遍，实测 7′41″）。九步编排在 `machine.py:159 Machine` + `run_agent.py`，带 `--attempts` 重试。
   ⚠️ 而且有一条**必须照搬的硬知识**：`steps/s7_minute.py:17-21` 记录 ——
   用 `TCM_SETCURSEL` 直接改下拉框会让**通达信整进程崩溃**，所以"必须用鼠标点 Tab"不是偷懒，是实测结论。

**状态监控与自愈也有现成的**：`watchman.py:79 probe()`（进程/主窗口/登录框/最小化/后台同步）
+ `:207 _loop` 每 `interval_min` 分钟一轮、不在线即 `heal()`，`:96 heal(force_restart=True)`
配 `reset.py:29 kill_all()`（TdxW/TdxSP/TdxNonSP + `Pyth*` 前缀），定时重启开关
`tdx_watch.restart_at`（`_restart_due` `watchman.py:243`），弹窗看门狗 `watchdog.py:90` 读
