## 2. 要加什么（三块维度 → 9 个新页）

### 维度一 · 数据获取（P0）—— 新模块「**数据链路**」

| 路由 | 页面 | 回答什么 | 数据从哪来 |
|---|---|---|---|
| `/pipeline` | 链路总览 | 下载→入库→校验→加工 每一环**最后成功是什么时候、卡在哪** | `config.job` + `operations.*` + 各表 `max(trade_date)` |
| `/tdx` | 通达信控制 | 进程在不在、登录没有、连上主站没、后台同步开没开；**手动触发盘后下载 / 重启** | `watchman.probe()` 结果**必须入库**（现在只写 `var/tdx_watch.json`，前端读不到） |
| `/coverage` | 数据覆盖体检 | 日线/1 分钟/5 分钟/板块/龙虎榜/自选 **各自覆盖哪段、缺哪几天** | 各表 `min/max(trade_date)` + 与 `trade_calendar` 交叉求缺口 |

> ⚠️ 关键已知缺口要**主动显示**，不能藏：分钟线只有 2026-09-22 一天（271 万行）。
> 这条直接决定"封板时间/首封时刻"这类指标历史上永远算不出来 —— 用户看得见才知道为什么页面是空。

## 5. 加一个页面要动哪些文件（照此表做，别自己摸）

| 动作 | 必改文件 | 会踩的测试 |
|---|---|---|
| 新独立模块 | `lib/workspace/modules.ts`（`MODULES` 新条目）、`router.tsx`、`pages/X.tsx`、`lib/x.ts` | **`modules.test.ts:7`（先修红）**、`:10-14`、`:28-31` |
| 模块下新子页 | `router.tsx`、`modules.ts`（`pages` + `CHAT_PAGES`）、`pages/X.tsx` | 同上 |
| 上首页卡片 | `lib/workspace/features.ts` 的 `FEATURE_GROUPS` | `workspace.test.ts:8-10`（断言 `.length=5` 与路径集合**等值**） |
| 运维页（不进主导航） | `router.tsx`、`components/layout/Layout.tsx:27,52-53` | `jobs.test.ts:136`（断言 Layout 含 `to="/jobs"`；且断言 MODULES **不得**含 /jobs） |
| 改自选 | `lib/watchlist.ts`（键名 + 迁移）、`pages/Watchlist.tsx`、`pages/MyStocks.tsx` | `audit-remediation.test.ts:23` |

**三条硬纪律**（今天都实测过）：

1. `tsc` 开了 `noUnusedLocals`/`noUnusedParameters`，且 `tsc -b` **先于** `vite build` —— 一个未用 import 就让 `manage.py auto` 里的 setup 失败、**服务起不来**（昨晚就是这么把 8910 弄停的）。
2. `tsc -b` 有 `.tsbuildinfo` 增量缓存，会报**已经修好的错**。先删 `frontend/**/*.tsbuildinfo` 再看。
3. 新页面的空态必须走 `available=false` + `reason`，**不许放示例数据/占位数字**。我们刚花一整份文档列 quantdash 的 43 处造假点，别再往自己页面上加。
