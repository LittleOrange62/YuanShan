### 已确认的缺陷清单（新系统必须避开）

**数据正确性**

- 日线 `amount` 写入单位为元，但 schema 文档声明千元 → **1000× 偏差**
- 分钟线 `vol` 写入单位为股，文档声明手 → **100× 偏差**
- `limit_up/limit_down = pre_close × 1.1/0.9` 一刀切 → 创业板/科创板/北交所全错
- `adjustment_factor` 硬编码 1.0 → 全部数据未复权
- `sync_minline.py` 日期锚点 `LO_BASE=45881` 是魔法常量，查找表只覆盖到约 2027-08

**逻辑缺陷**

- `core/factor_engine.py:478` 调用 `calc_y_at_date` 漏传第 4 个参数 `block_stocks` → `bankuai` 恒为 0 → **Y 轴 65% 的板块热度权重完全失效**，影响已存的 75,995 条打分记录
- `scripts/score_*d_*.py` 四个脚本用 `get_recent_dates()` 取当前窗口，无视传入的历史 `date_str` → 回溯计算全错
- `scheduler.py:229-242` `_is_trading_day` 算了 `latest`/`today` 却三个 return 全是 `weekday() < 5` → **不认节假日**
- `web/helpers.py:86` 用了 `dbc.Alert` 但没 import `dash_bootstrap_components` → 必然 NameError，影响 4 处调用
- `core/software_manager.py` 4 个功能被 early-return 禁用，但 UI 仍显示永不触发的倒计时

**安全**

- `sql_api_auth_enabled` 默认 `False` → data 与 sql 两组 API 默认无认证，监听 `0.0.0.0:8765`
- `/api/sql/execute` 只黑名单 `select`/`with` 开头的语句，`ATTACH DATABASE '任意路径'` 可完全绕过目录限制、库白名单和只读限制
- `/api/exec` 用 `subprocess.Popen(shell=True)` 无白名单；且 `for line in proc.stdout` 阻塞在 `proc.wait()` 之前，超时失效 —— 泄漏两次整个任务 API 死锁
- `/api/sql/health`、`/api/exec/enabled` 完全无认证；Worker 8766 零认证
- 通达信明文口令硬编码在 3 处（`open_tdx.ps1:10-11`、`type_creds.ps1`、`type_creds2.ps1`）
- `web/api_client.py` 多处 f-string 拼 SQL；`helpers.esc` 自述"临时方案"

**工程**

- 三套 MCP 实现并存：`mcp_service.py`（真实在跑）、`core/mcp_server.py`（57 工具，死代码，仅进程管理部分被用）、`mcp_server_simple.py`（完全孤立）
- 两套任务队列并存：`core/task_queue.py`（进程内，Tk 绑定，`web/` 零使用）、`core/worker_*`（跨进程 HTTP 8766）；两者都不持久化任务
- 取消功能是假的：`/api/task/cancel` 只改内存状态，handler 拿到的 Event 永不 set，`_finish_task` 又覆盖回 done/error
- 守护链只覆盖 web（Task Scheduler → `web_run_with_retry.py` → `run_web.py --prod`），MCP 8765 与 Worker 8766 无守护
- 日志 213 MB 无轮转（`web_stderr.log` 113 MB、`mcp_stdout.log` 33 MB、`crash.log` 29 MB）；`core/logger.py` 在 `__init__` 里开一次文件，跨天不切
- 项目根目录 3 个 0 字节僵尸 DB + 7 个孤儿 `-wal`（约 35 MB，其中 5 个没有主库文件）—— 相对路径开库导致
- `libs/` 是死重量且是地雷：`libs/pandas` 是源码布局，一旦加入 sys.path 会遮蔽全局编译版 pandas，导致 `core` 与 `tabs` 全部 import 失败
- `fin.bat`、`web/api_client.py:run_command` 等多处硬编码 `d:\finance`
- `project_notes/overview.md` 已过时：称 web 是 Flask/Quart（实际 Dash）、引用不存在的 `query/` 模块
