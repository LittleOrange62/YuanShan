这份放在**脚本旁边**，是给改脚本的人看的：这一族每一路是第几号、任务名叫什么、脚本在哪个文件、
默认几点跑、属于哪一层、这一路干什么。**一句话功能列控制在 20 字以内**，多的一律算不合格。

- **真源不是这张表**：时点/渠道/开关落在 `app/intraday/tasks.py` 的 `SPEC` + 作业配置
  `jobs/config.json` 的 `intraday_broadcast`；判据与正文在各路脚本与 `app/intraday/templates.json`。
- **最后一列那十一个短句不在这里维护**：字面住在 `app/intraday/tasks.py` 的 `BRIEF`，
  「推送任务」那一屏的行末读的是同一份（11-06 起）。这张表里的这一列必须与 `BRIEF` **逐字相等**，
  由测试钉住（`tests/test_intraday_broadcast_tasks.py::test_本地清单与在册表逐行不漂`）；
  改句子只改 `BRIEF` 一处，然后把这张表那一列改成一样的字，跑一遍那个文件就知有没有对齐。
- 这张表由 `tests/test_intraday_broadcast_tasks.py::test_本地清单与在册表逐行不漂` 钉住 ——
  加了新的一路、改了任务名或脚本路径而没改这里，测试当场红。
- 界面（改节奏的地方）：`/push-tasks`「推送任务」那一屏。保存 = 写配置 + 覆盖式重注册 Windows 计划任务；
  关掉某一路 = **注销**它的任务，不是留个每天空跑不出声的任务。

## 三条要知道的规矩

1. **都是每日触发器**：周末和节假日到点照样起进程，该不该跑由**脚本内**判。交易日判据只有一份，
   住在 `t01_zt_watch.is_trading_day()`（日历读不出来时按周末兜底不播）；盘中那几路再各判一道时段闸。
   新加一路到点播报，第一件要问的就是这两道闸走的是不是那一份。
2. **③④⑤⑦⑧⑨⑩⑪ 只读库**：一次源站都不碰，所以任何一发都能事后重跑、正文与当时一字不差 ——
   `t03_zt_delta --since HH:MM`、`t07_sysentry_report --at HH:MM:SS`、`t09/t10 --send --resend`、
   `t11 --resend`（补发今天已落库那条）／`t11 --date YYYY-MM-DD --dry-run`（把某一场重排一遍看看）。
   库里今天没有那一针的数时，它们播一句「未就绪」并写清为什么，**不写"0 只"、不拿昨天顶**。
3. **①⑥ 是"发 0 条"正常的那两行**：它们本来就不发送，只落 `analytics.intraday_pool_event`／
   `analytics.intraday_sysentry`；发送归 ③ 与 ⑦。屏上那两行会写明"发送归哪一路"。
4. **⑪ 那一栏的判据不住脚本里**：六档预设模式、阈值、三条证据、最近 5 场趋势全在
   `duanxian/strong_mode.py`（阈值实值在 `app/intraday/broadcast_config.json` 的 `sm_*` 那 14 格，
   **不在系统配置界面上** —— 改它等于改每天往群里发什么）；逐档读数另落
   `analytics.strong_mode_daily`，`t11 --backfill 30` 手工补历史。
5. **正文必须在发送之前落库**（`analytics.intraday_broadcast.body`，`what` 用那一路自己的名字），
   发完再写一条 `what='sent'` 的回执 —— 两行**同一个 `now`**，屏上「按日期回看推送正文」读的就是
   发送前那一行，`--resend` 读的也是它。改脚本时不要把 `_log(..., body=text)` 挪到 `_send()` 之后，
   也不要在降级分支里只写 `err` 不写 `body`（⑤ 的 `noon_stale` 那一支 11-10 之前就是这样，
   发送中途崩掉就一个字都留不下）。钉它：`tests/test_broadcast_bodies.py` 与
   `tests/test_noon_review.py::test_池子取不到那一路也是先落正文再发`。
   ①⑥ 两路不在这条规矩里（它们不发送，`body` 里存的是池摘要），回看那一列由
   `app/intraday/tasks.py::PUSH_KEYS` 把它们剔掉。
6. **正文排版（11-18 起）**：飞书卡片正文用 Markdown 加粗突出三类行——**标题行、聚合行、
   分区小标题**（`templates.json` 里那批 `**…**`；数据行保持素文，不新加 emoji，沿用既有 🟢🔻⚡）。
   改文案要保住 `**` 位置；改占位符必须把那一路 `--dry-run` 跑一遍再交。
   微信镜像（⑧）发送前 `_strip_md` 剥掉星号，两渠道各看各的样式。

## 现在开着的还是关着的（11-10 现读 + 本路登记后）

①–⑧ 开着；⑨⑩ 的开关由用户自己打开过（正文是他自己写的），机器上两个任务都在；
**⑪ 出厂默认关着**（`strong_mode_enabled: False`），11-10 用户点名「每天 19:19 准时跑」⇒
现网配置里已按他的要求打开并注册（`python -m app.intraday.tasks --set strong_mode_enabled=true --apply`）。
关着的语义就是**连任务都不注册**，屏上那一行会说"这一路已关" —— 打开的那一下等同于
"每天 19:19 真往群里发一条"，所以这一路出厂不敢默认打开。
