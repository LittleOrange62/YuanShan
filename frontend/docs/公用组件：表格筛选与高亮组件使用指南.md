## 概述

本项目提供了两个通用的表格交互组件，可以快速为任何数据表格添加：
- **列筛选功能**：支持多种筛选类型（下拉选择、范围框定、布尔值、最小值）
- **单元格高亮**：点击单元格时高亮所在行和列

## 组件清单

### 1. `TableFilterPanel` + `FilterToggleButton`

**文件位置**: `src/components/ui/TableFilterPanel.tsx`

**功能**: 提供可展开/收起的筛选面板，支持4种筛选类型

**使用示例**:

```tsx
import { FilterToggleButton, TableFilterPanel } from "@/components/ui/TableFilterPanel";
import { useState } from "react";

export function MyTablePage() {
  const [showFilters, setShowFilters] = useState(false);
  const [filters, setFiltersState] = useState<{
    board?: string;
    dbl_count_min?: number;
    chg_today_min?: number;
    chg_today_max?: number;
  }>({});

  // 在渲染数据前应用筛选
  const filteredRows = rows.filter(r => {
    if (filters.board && r.board !== filters.board) return false;
    if (filters.dbl_count_min !== undefined && (r.dbl_count ?? 0) < filters.dbl_count_min) return false;
    if (filters.chg_today_min !== undefined && (r.chg_today ?? -Infinity) < filters.chg_today_min) return false;
    if (filters.chg_today_max !== undefined && (r.chg_today ?? Infinity) > filters.chg_today_max) return false;
    return true;
  });

  return (
    <>
      {/* 筛选按钮（带激活计数徽章） */}
      <FilterToggleButton 
        show={showFilters} 
        activeCount={Object.values(filters).filter(v => v !== undefined).length} 
        onClick={() => setShowFilters(!showFilters)} 
      />

      {/* 筛选面板 */}
      <TableFilterPanel
        show={showFilters}
        filters={filters}
        onChange={(key, value) => setFiltersState(f => ({ ...f, [key]: value }))}
        onClear={() => setFiltersState({})}
        sections={[
          { label: "板块", type: "select", key: "board", options: [
            { value: "主板", label: "主板" },
            { value: "创业板", label: "创业板" },
          ]},
          { label: "倍量次", type: "range", key: "dbl_count", min: 0 },
          { label: "当日涨幅", type: "range", key: "chg_today", step: 0.1 },
        ]}
      />

      {/* 表格渲染时使用 filteredRows */}
      <table>
        <tbody>
          {filteredRows.map((r, i) => (
            <tr key={i}>...</tr>
          ))}
        </tbody>
      </table>
    </>
  );
}
```

### 2. `useTableCellHighlight`

**文件位置**: `src/lib/useTableInteraction.ts`

**功能**: 单击一格 → 整行＋整列一起高亮。

⚠️ **2026-10-26 起，选中态不在 React 里**（下面这份用法跟着变了）。
原先它是一份 `useState`，每格 className 都跟着选中态变 ⇒ 一次单击要让整表重新协调一遍：
`/volume-double` 那张 800 格的表实测**一次单击 461 毫秒的长任务**，而 React 把第一格改动提交出去只要 6~10 毫秒。
行级 `React.memo` 治不了（列高亮动到每一行的那一格，每行 props 都变）。
现在的做法：每格 className 是**静态**的（与选中无关），点击时在 DOM 上给行／列／交叉那一格各标一个类
（`.xl-row`/`.xl-col`/`.xl-cell`，颜色只住 `src/index.css`）。实测同一族屏幕的单击：
1,140 格 1.1 毫秒、4,800 格 4.1 毫秒、13,380 格 4.3 毫秒，且**记不到长任务**（`PerformanceObserver('longtask')` 现测）。

**使用示例（调用方优先用 `useStockRowInteraction` 那一层，见 §3）**：

```tsx
import { useTableCellHighlight } from "@/lib/useTableInteraction";

export function MyTablePage() {
  // 返回的是 store（可订阅），不是 selectedCell —— 读选中态要看下面那条红线
  const { store, handleCellClick, clearSelection, getCellClass, getRowClass } = useTableCellHighlight();

  return (
    <table>
      <tbody>
        {rows.map((row, rowIdx) => (
          <tr key={rowIdx} className={getRowClass(rowIdx)}>
            {Object.entries(row).map(([key, value]) => (
              <td
                key={key}
                className={getCellClass(rowIdx, key, "base-class")}
                // ⚠️ 第一个参数是被点那一格（e.currentTarget），不是行号：
                // 一屏多张表时只有格子自己知道自己属于哪张 <table>，行列号会在两张表里都对上号。
                onClick={(e) => handleCellClick(e.currentTarget, rowIdx, key)}
              >
                {value}
              </td>
            ))}
          </tr>
        ))}
      </tbody>
    </table>
  );
}
```

⚠️ **要在渲染里读"现在选中哪一格"**（点完顺手展开档案、发一发按代码取数的请求那一类），
只准用 `useCellSelection(store)`，而且**必须放在依赖它的那一小块子组件里**：
提到页面组件本体，整张表就又回到"每次点击重渲染一遍"，这一条改动就白做。
现成的两个先例：`pages/Confluence.tsx` 的 `FocusPane`（档案＋历史）与
`pages/Grouped.tsx` 的 `SelectedHint`（已选中哪一只那一句）。
闸在 `test/tableHighlight.test.ts`（反向钉住"订阅不许出现在页面组件那半截文件里"）。
另有一条既有规矩仍然生效：页面不许直接 `import` 低一层的 `useTableInteraction` ——
`useCellSelection` 与 `CellStore` 由 `useStockRowInteraction` 转出口（闸在 `test/groupedDossier.test.ts`）。
### 3. `useTableFilter` (Hook版本)

**文件位置**: `src/lib/useTableInteraction.ts`

**功能**: 提供通用的筛选逻辑封装（适合复杂场景）

**使用示例**:

```tsx
import { useTableFilter } from "@/lib/useTableInteraction";

export function MyTablePage() {
  const { filters, setFilter, clearFilters, applyFilter, activeCount } = useTableFilter<MyRowType>();

  const filteredRows = applyFilter(rows);

  return (
    <>
      <button onClick={() => setFilter("board", v => v === "主板")}>只看主板</button>
      <button onClick={clearFilters}>清除筛选</button>
      <p>当前激活 {activeCount} 个筛选条件</p>
      {/* 渲染 filteredRows */}
    </>
  );
}
```

## 筛选类型说明

| 类型 | 适用场景 | 配置项 | 示例 |
|------|---------|--------|------|
| `select` | 枚举值选择 | `options: [{value, label}]` | 板块、象限档 |
| `boolean` | 是/否判断 | 无 | 贴MA60、是否ST |
| `range` | 数值范围 | `min`, `max`, `step` | 涨幅、倍数、天数 |
| `number-min` | 单边界最小值 | `min` | 最少倍量次 |

## 注意事项

1. **筛选逻辑在前端**：当前实现是前端过滤，大数据集（>1000行）建议后端加筛选参数
2. **空结果提示**：筛选后`filteredRows.length === 0`时要给出明确提示（是筛空的还是没数据）
3. **筛选状态持久化**：如需刷新页面后保留筛选条件，可将`filters`存入URL参数或localStorage
4. **性能考虑**：`applyFilter`使用了`useCallback`，不会因组件重渲染而重复计算
